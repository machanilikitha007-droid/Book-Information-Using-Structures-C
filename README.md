# Book Information Using Structures in C

## Project Description

A simple C program that uses a structure to store and display information about a book.

## Features

- Enter book details
- Store book information
- Display book details

## Technologies Used

- C
- Structures
- Variables

## How to Run

Compile and run the `book_information.c` file using a C compiler.
